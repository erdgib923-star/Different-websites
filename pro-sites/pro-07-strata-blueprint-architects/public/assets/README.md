# Image slots: Plinthwell Architects

All imagery is technical drawings generated by `src/drawings.js`. They are pre-rendered into the HTML at build time.

Every `figure.media[data-slot]` can take a real photo or render instead:

1. Put the file in `public/assets/images/`.
2. Add `"slot-name": "file.jpg"` to `public/assets/images/photos.json`.
3. Reload. The photo lazy-loads and blurs up. Set `--duo-dark` and `--duo-light` on the figure to tint it (for example `--duo-dark: var(--neutral-900); --duo-light: var(--neutral-50)` for a concrete-grey duotone), or `--tint-strength: 0` to keep its true colour.

| Slot | Section | Aspect ratio | Recommended size |
|---|---|---|---|
| `walk-site`, `walk-massing`, `walk-structure`, `walk-facade` | Process walkthrough frames | 40:26 (≈ 3:2) | 1600 × 1040 |
| `depot-before` | Before/after: before layer | 16:10 | 1920 × 1200 |
| `depot-after` | Before/after: after layer | 16:10 | 1920 × 1200, same framing as "before" |
| `project-kiln-street-studios`, `project-sallow-quay`, `project-brackenford-library`, `project-kiln-street-depot`, `project-ropewalk-flats`, `project-eastwold-fire-station`, `project-mill-lane-offices`, `project-granary-rooms`, `project-tallis-row` | Project index cards | 4:3 | 1200 × 900 |

For the before/after slider, both photos must share the same camera position and crop, or the comparison won't line up. The hero elevation and the floor plan are drawings by design and have no photo slot.
