# Image slots: Mossmere

Each `figure.media[data-slot]` shows a code-drawn "garden window": an arch, hills, an orb and sprigs, generated by `src/botanica.js` and injected at build time. It stays until you list a photo in `public/assets/images/photos.json`. The illustrations use theme tokens, so they switch between day and night with the rest of the page.

## Adding a photo

1. Put the file in `public/assets/images/`.
2. Add `"slot-name": "file.jpg"` to `photos.json`.
3. Reload. The photo lazy-loads, blurs up and is duotoned from deep moss (`--duo-dark`) to cream (`--duo-light`). Set `--tint-strength: 0` on the figure to keep the natural colour.

| Slot | Section | Aspect ratio | Recommended size |
|---|---|---|---|
| `valley` | "A slower kind of green" | 4:5 | 1200 × 1500 |
| `cabin-fern` | Cabins, first | 4:5 | 1200 × 1500 |
| `cabin-moss` | Cabins, second | 4:5 | 1200 × 1500 |
| `cabin-lantern` | Cabins, third | 4:5 | 1200 × 1500 |

The arch framing is part of the illustration only. Photos fill the rounded card.
