# Quillstack: bento notes app demo

> **Quillstack is a fictional brand.** The product, pricing, statistics, notes, address (12 Pier Lane, Example Harbour), email (hello@example.com) and phone number ((555) 555-0100) are all invented sample content.

## Concept
A landing page for a calm notes and writing app, built as a **bento grid of nine live tiles**. Each tile is a working mini-UI, not a screenshot:

| Tile | What it does |
|---|---|
| Distraction-free editor | Types a short paragraph with a blinking caret. There is a **Pause typing** button (WCAG 2.2.2). It pauses offscreen and in hidden tabs, and shows the full text under reduced motion. |
| Draft board | A kanban board. Select a card to move it one column right; the move is animated with View Transitions. A polite live region announces each move. |
| Writing streak | This month's calendar. Toggle the days you wrote; the count updates. |
| Night desk | `role="switch"` theme toggle for the whole page, remembered in localStorage. |
| Tags | Toggle tags to narrow a sample note count. |
| This week | Count-up word total and a 7-bar chart. Bars grow in when the tile pops in; the chart has a text alternative. |
| Backlinks | Note graph that highlights its edges on hover. |
| Focus timer | A working 25-minute timer with a progress ring and live-region status. |
| Quick capture | Form that adds notes to a recent list. |

Each tile's **expand button** opens a detail dialog. The tile morphs into the dialog with the **View Transitions API**. Fallback: a CSS scale-and-fade on `dialog[open]`. Tiles **tilt toward the cursor** on fine pointers only, never under reduced motion.

### Design direction
1. A writer's desk from above: paper-white surfaces, ink-blue structure, one coral spark.
2. A bento grid where every tile is a real, usable mini-UI.
3. Bricolage Grotesque gives the display type tension; Instrument Serif italic is the "handwritten" voice (`<em>`).
4. Motion tells the product story: capture, shape, link, publish, in one pinned and scrubbed sequence.
5. Details: hairline borders, ink-tinted shadows, grain over every large gradient.

## Color Brief
- **Mood:** quiet focus, ink on good paper, with one warm spark of energy.
- **Hue anchors (OKLCH):** ink-blue **255** (brand), coral **30** (accent). Neutrals are tinted toward 255 at chroma 0.014.
- **Harmony:** blue against coral, a warm/cool opposition. Note: in OKLCH degrees the two hues are 135° apart, so strictly this is near-complementary (split-complementary side), not a 180° complement. I kept the hues you specified; the warm/cool opposition still does the complementary job.
- **60 / 30 / 10:** 60% paper neutrals (`bg`, `surface`), 30% ink-blue (type accents, buttons, charts, CTA band), 10% coral (badges, caret, progress bar, highlights).
- **Themes:** light, plus a dark "night desk" built from ink-tinted near-blacks (`night-0…3`) rather than pure black.
- **Data colours:** the chart uses one blue for all bars and coral for the highlighted day. Blue and orange stay distinguishable under protanopia, deuteranopia and tritanopia, and the highlight is also named in the chart's text alternative.

All colours are OKLCH custom properties generated by `scripts/palette.mjs` from `palette.config.mjs`:
- 11-step ramps (50–950) for `neutral`, `brand` and `accent`, gamut-mapped into sRGB;
- semantic tokens: `bg`, `surface`, `surface-2`, `text`, `text-muted`, `border`, `accent`, `accent-contrast`, `focus` (plus `brand`, `brand-text` and `border-strong`);
- hex fallbacks inside `@supports not (color: oklch(0 0 0))`.

Gradients use `in oklch` interpolation, with a plain gradient declared first as the fallback. Shadows mix `--shadow-color` (brand-950, or night-0 in dark) instead of black. The hero desk and the CTA band use the `.grain` SVG-noise overlay against banding.

## Motion system
Tokens live in `src/styles/motion.css` (CSS) and `src/lib/motion.ts` (GSAP):
- **Durations:** 0.4 / 0.7 / 1.0 / 1.2 s.
- **Easing:** expo-out `cubic-bezier(0.16,1,0.3,1)` and power3-out.
- **Stagger:** 75 ms.
- **Pop preset:** scale 0.9 → 1.02 → 1, translateY 24px → 0, opacity, blur 8px → 0.

| Section | Choreography |
|---|---|
| Hero | Word-by-word split-text rise for the h1, then staggered fade-ups. Two badges pop with overshoot at 0.9 s and 1.1 s. **Parallax pair:** the back sheet, front sheet and pen move at three speeds. |
| Bento | Nine tiles pop in staggered; chart bars grow; the streak calendar is built live. |
| Workflow | **Pinned and scrubbed** GSAP ScrollTrigger timeline (300% of scroll). Scraps fly into an outline, links draw in, then the published card rises. Badges "+ 3 backlinks" and "Published ✓" **pop at fixed scroll positions** (timeline 2.5 and 3.8). Progress dots track the step. |
| Pricing | Staggered card pops; the "Our pick" badge pops 500 ms later. |
| CTA | Split-text heading, staggered buttons, device figure pop. |
| Global | A reading-progress bar scrubbed by `animation-timeline: scroll()`. |

**CSS scroll-driven first:** parallax and the progress bar use `animation-timeline` under `@supports`. Without it, a GSAP ScrollTrigger scrub takes over; you can force that path with `?nosda` in the URL. Discrete pop-ins are time-based and triggered by IntersectionObserver, because a pop with overshoot reads better on a clock than scrubbed against the scrollbar. Lenis smooth scroll is driven by the GSAP ticker.

**Progressive enhancement:**
- Hidden start states exist only under `html.js`. An inline watchdog removes `js` if the module fails to boot within 4 s.
- Without JS, every section is readable and the workflow shows its finished state as a list.
- Under `prefers-reduced-motion`: final states show instantly. There is no pinning, parallax, Lenis, tilt or typing autoplay, and View Transitions are skipped.
- Nothing flashes: the caret blinks about once per second.

```bash
npm install

npm run build      # type-check + production build to dist/
npm run preview    # serve dist/
npm run palette    # regenerate src/styles/tokens.css from palette.config.mjs
npm run contrast   # verify contrast and refresh the table above
```

## Swap in your own photos
Image slots are `<figure class="fig" data-slot="…" data-photo="">` components. Put a photo in `public/assets/images/` and set `data-photo="assets/images/your-file.jpg"`. It lazy-loads near the viewport and sharpens from a blur over the slot's dominant-colour placeholder. The duotone overlay keeps it on palette: set `--fig-duo: 0` on the figure for a natural photo. See [`public/assets/README.md`](public/assets/README.md) for every slot and its recommended size.

## Notes and decisions
- Built as a folder in `erdgib923-star/different-websites`, not as its own GitHub repo: `gh` was not authenticated in this session and repo creation was not available. The folder is self-contained so you can split it into its own repo (see `style-sites-2/README.md`).
- Brand check (web search, 2026-11-02): the only use of "Quillstack" I found was a design-gallery mock-up; no real product. The name was kept.
- Fonts are self-hosted from `@fontsource` npm packages (Google Fonts families, `font-display: swap`), so the page makes no third-party requests.
- **Build fix (2026-11-03, after site 19):** `vite.config.ts` now sets `build.cssTarget` to oklch-capable browsers (Chrome/Edge 111, Firefox 113, Safari 16.4). Before this, Vite's CSS minifier rewrote every oklch() token to lab(). Chromium then dropped the hue in `color-mix(in oklch, <lab colour>, transparent)` and tinted translucent surfaces (headers, shadows, glows) slightly pink. Older browsers still use the hex fallbacks. After the change I rebuilt and re-audited at 1440 px (axe, console, reduced motion, no-JS, `?nosda`); new screenshots were not taken.
- The same re-audit flagged `.published p` (the white caption on the blue 'published' card) at 4.47:1, because of `opacity: 0.9`. I removed the opacity, and a second re-audit showed 0 violations.
