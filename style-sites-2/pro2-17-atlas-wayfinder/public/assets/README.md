# Image slots

Put photos in `public/assets/images/` (served as `assets/images/…`) and set `data-photo` on the slot in `index.html`. Until then each slot shows a watercolour-style wash drawn on canvas (`src/wash.ts`).

| Slot (`data-slot`) | Where | Aspect ratio | Recommended size | Notes |
|---|---|---|---|---|
| `deck` | Log, large figure (parallax, drifts up) | 3:2 | 1500 × 1000 px | A deck or seascape at dusk. |
| `harbour` | Log, small figure (parallax, drifts down) | 4:5 | 1000 × 1250 px | A harbour or shoreline in the morning. |

The chart is not a photo slot. It is an inline SVG generated by `scripts/build-map.mjs` (`npm run map`). Do not replace it with map tiles: the scroll animation depends on the route path and markers inside the SVG.

Hooks on each `<figure>`:
- `--fig-duo`: `1` (default) renders the photo as an ink → parchment duotone, like an old print; `0` keeps natural colour.
- `--fig-shadow` and `--fig-highlight` set the duotone ends.
- `--fig-placeholder` is the colour shown while the photo loads.
