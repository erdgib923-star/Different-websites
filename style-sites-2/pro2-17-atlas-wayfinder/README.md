# Atlas Wayfinder: a scroll-driven sea chart for a fictional voyage

> **Everything here is fictional.** Atlas Wayfinder, the Lanternfall Isles, every island (Saltmarrow, Quill Island, Brannock Reef, Hollow Skerry, Ember Cay, Farlight), distance, date, price, berths@example.com and (555) 555-0100 are invented. The chart is **not for navigation**.

## Concept
A twelve-day small-ship voyage told on a **hand-built SVG chart** (no map tiles, no map data):
- **The chart** is generated by `scripts/build-map.mjs` and written into `index.html`, so it is real markup that works without JS.
  - Coastlines are seeded noisy circles smoothed with Catmull-Rom curves.
  - Each island has dashed shoal lines, a hill tint and an italic label; Brannock Reef gets a dotted reef pattern.
  - The chart also has a wave texture, a dotted graticule, a lighthouse, sea names, a scale bar and a compass rose.
- **Pinned voyage** (`src/voyage.ts`):
  - Scrolling **draws the route** (solid coral over the dashed planned line) and moves a small boat along it.
  - The **camera follows the boat** by animating the SVG `viewBox`: it zooms out a little mid-leg and back in at each anchorage, with a whole-chart overview at the start and end.
  - The boat **dwells** at each anchorage.
  - The **compass needle turns to the boat's heading**.
  - Each **numbered waypoint marker pops** when the boat arrives, and that island's **card pops in** beside the chart, along with the day and the nautical miles sailed.
- **Hero compass rose** turns a quarter as you scroll away (CSS scroll timeline, GSAP fallback).
- **Log** section with a **parallax pair** of watercolour-style washes (canvas).
- **Sailings** table with fictional 2027 dates and prices.

### Design direction
1. An old sea chart kept in a captain's drawer: parchment, ink, a single coral line.
2. The page *is* the map; the story is told by moving across it.
3. Cormorant for titles and chart lettering; Lora, a sturdy book serif, for reading.
4. Motion follows the voyage: draw, sail, arrive, pop. Nothing moves without a reason.
5. Calm spacing on a 4/8/12/16/24/32 rhythm.

## Color Brief
- **Mood:** unhurried, curious, sunlit, salt-faded.
- **Hue anchors (OKLCH):**
  - **parchment 85** (paper, land);
  - **ocean teal 200** (brand): the sea, links, buttons, the "berths left" chips;
  - **coral 30** (the one accent): the route, waypoint markers, kickers, the compass north.
- **Harmony:** near-complementary teal and coral on a warm neutral paper.
- **60 / 30 / 10:** 60% parchment, 30% sea and ink, 10% coral.
- **Neutral ramp:** tinted toward teal (200, chroma 0.012), so the "ink" is a deep sea-tinted neutral, never black.
- **Map text:** labels sit on the sea with a sea-coloured halo (`paint-order: stroke`). The contrast table checks ink on sea and ink on land.
- **Data colours:** the berth chips use teal for normal and coral (with a parchment numeral) for "almost full". The number is always written, so colour is never the only signal.

All colours are OKLCH custom properties from `palette.config.mjs`:
- 11-step ramps;
- named parchment, land, ink, sea and coral colours;
- semantic tokens: `bg`, `surface`, `surface-2`, `text`, `text-muted`, `border`, `brand`, `brand-contrast`, `accent`, `accent-text`, `accent-contrast`, `focus`, `shadow-color`;
- hex fallbacks under `@supports`.

The paper texture is a static fractal-noise tile. Shadows are ink-tinted. There are no large gradients.

## Motion system
Shared tokens (0.4/0.7/1.0/1.2 s, expo and power3 easing, 75 ms stagger, pop preset without blur).

| Section | Choreography |
|---|---|
| Hero | Split-words title, lead and button rise. The compass rose turns 90° as the hero scrolls away (scroll timeline). |
| Voyage | **Pinned and scrubbed** (650% of scroll, all widths): route draw, boat and camera follow, compass heading. **Waypoint markers pop on arrival**, and cards swap with a rise. |
| Log | **Parallax pair** (-0.35 / +0.4); split heading; the facts pop in a stagger. |
| Sailings | Split heading; the table and contact line rise. |

- **Smooth scroll:** Lenis.
- **Reduced motion:** the whole chart with the full route and all six markers, and the six cards as a list. There is no pin, no camera move, no rose turn, no parallax and no smooth scroll.
- **No JS:** the same static chart and list, because the chart is plain SVG markup.

## Skills actually used
- `paper` (bergside, loaded for this site): the 4/8/12/16/24/32 spacing rhythm, a minimal paper surface, explicit states, WCAG AA. Its Roboto/Montserrat fonts were replaced by the brief's Cormorant + Lora.
- `frontend-design` and `css-animation-patterns`, loaded earlier in this session and applied again: a committed direction, scroll timelines and the reduced-motion pattern.
- `motion-and-interaction-system` (read manually).
- **Not available**, so not used: gsap, scroll-experience, color-expert, accesslint, web-design-guidelines. The audit used axe-core.

## Run and build
```bash
npm install
npm run dev
npm run build
npm run preview
npm run map       # regenerate the chart SVG inside index.html
npm run palette
npm run contrast
```
To move an island or the route, edit `ISLANDS` / `ROUTE` in `scripts/build-map.mjs` and run `npm run map`. The voyage script finds each anchorage on the route by itself.

## Verification (what was actually run)
- `npm run build` passes; `npm run contrast`: 15/15 pairs pass.
- Headless Chromium at 375, 768 and 1440 px, with screenshots at 0/25/50/75/100%:
  - no console errors, no failed or external requests, one h1, no horizontal scroll;
  - axe-core: 0 violations;
  - reduced-motion and no-JS passes: nothing hidden. The no-JS full-page screenshot shows the whole chart, the route and the six cards.
- Probes at 375 px:
  - at 42% of the voyage pin, markers 1–3 were on, the card read "Brannock Reef" (Day 4, 51 nm), and the camera was zoomed on that island;
  - at 97%, all six markers were on, the card read "Farlight", and the camera had pulled back to the whole chart.
- **`?nosda` pass:**
  - The audit's fast jump-scroll reported the Log and Sailings pop-ins as still hidden 1.8 s after reaching the bottom. A probe showed why: Lenis was still easing toward the bottom (scrollY 6302 of 8376).
  - After 5.8 s, everything had revealed.
  - So it is a late reveal, not a stuck one, but it suggests the per-frame SVG `viewBox` changes are heavy in software rendering. Real-device performance is **not tested**.
- Fixed before the first commit, from the first audit and screenshots:
  - coral day labels on cards were 4.16:1, so `coral-deep` was darkened from L 0.52 to 0.49 and a pair was added;
  - waypoint markers jumped to the chart origin because the CSS pop transform replaced their SVG `translate`, so the pop now animates an inner group.
- **Not tested:** Safari and Firefox (Firefox uses the GSAP fallback for the rose and parallax), real devices, screen readers.

## Notes and decisions
- Built in `style-sites-2/` of `erdgib923-star/different-websites` instead of its own repo: `gh` was not authenticated and repo creation was unavailable. Split later with `publish-repos.sh`.
- Brand check (web search, 2026-11-03): no product or company called exactly "Atlas Wayfinder" was found. There are unrelated "Atlas" travel apps and "Wayfinder" navigation and hiking apps. I kept the name as fictional, with this note.
- The voyage pins at every width: the chart is at the top of its section, so the pin starts in view on phones too. Phones get a taller crop of the chart and a shorter card.
- Fonts are self-hosted via `@fontsource` (`font-display: swap`).
- **Build fix (2026-11-03, after site 19):** `vite.config.ts` now sets `build.cssTarget` to oklch-capable browsers (Chrome/Edge 111, Firefox 113, Safari 16.4). Before this, Vite's CSS minifier rewrote every oklch() token to lab(). Chromium then dropped the hue in `color-mix(in oklch, <lab colour>, transparent)` and tinted translucent surfaces (headers, shadows, glows) slightly pink. Older browsers still use the hex fallbacks. After the change I rebuilt and re-audited at 1440 px (axe, console, reduced motion, no-JS, `?nosda`); new screenshots were not taken.
