# Mochi Money: claymorphism savings app demo

> **Mochi Money is a fictional brand.** It is not a bank and holds no real money. The prices, savings story ("Pip"), statistics, address (7 Marshmallow Row, Example Town), email (hello@example.com) and phone ((555) 555-0100) are all sample content.

## Concept
A savings app for 6 to 12 year olds, in **high-fidelity claymorphism**: soft, inflated cards lit from the top-left, with layered outer and inner shadows tinted by each candy's own darker rim (never black). The parts:
- **Clay cards and buttons** use a 4-layer shadow stack. Buttons **squish** on press (`scale(.92)` plus an inset "pressed" shadow). On release, a GSAP elastic spring bulges them sideways and wobbles them back.
- **Bouncy pop-ins**: this site overrides the kit's pop easing with a back-out spring.
- **Coin-jar simulator** (`src/sim.ts`):
  - inputs: a goal, weekly pocket money (slider), the share that goes in the jar (slider), and an optional grown-up match (+25%);
  - outputs: the weekly amount, the weeks to the goal and an approximate ready date;
  - "Drop this week's coins" drops clay coins into an SVG jar with a bounce, and the jar fill rises on a CSS `linear()` spring;
  - a debounced live region announces the result, without chattering while a slider is dragged.
- **Pinned "year in the jar"** (`src/year.ts`): scroll fast-forwards a sample year. The jar fills, the month and amount tick over, and milestone badges pop at $10, $60 and $120.

### Design direction
1. A toy-shop shelf of soft vinyl clay: every surface bulges, nothing has a sharp corner (20 to 56px radii).
2. Six candy hues at the same lightness, so no colour shouts; plum carries all the reading.
3. Fredoka for round, friendly headings; Nunito for calm, readable body text.
4. Motion is physical: squish on press, bounce on entry, coins that land with a bounce.
5. Grown-up trust is stated plainly: approvals, no ads, nothing to buy.

## Color Brief
- **Mood:** sweet-shop cheerful but calm, safe, tactile.
- **Hue anchors (OKLCH):**
  - six candies at **L 0.82, C 0.09**: cherry 20, apricot 60, mint 150, sky 200, grape 290, bubble 340;
  - **plum 320** for all text and the brand ramp;
  - **mint 150** is the one accent ramp (savings figures, the jar fill, the toggle on-state).
- **Harmony:** an equal-lightness hue wheel (the six candies) anchored by a deep plum. Mint sits about 170° from plum, near-complementary, so savings numbers stand out from the plum text.
- **60 / 30 / 10:** 60% lavender-white canvas and white clay surfaces, 30% candy clay, 10% plum buttons and mint highlights.
- **Pastel contrast checked hard.** Because the candies share one lightness, one text colour works on all of them. Both plum text (9.7 to 10.4:1) and muted plum (4.84 to 5.19:1) are checked against every candy. White text is never placed on candy. The focus ring uses the darker plum-800 (5.96:1 on the darkest candy, up from 3.05:1 at plum-600).
- **Data colours:** this site has no charts. The simulator's jar is mint against a light well, with the amount also given as text.

Colours are OKLCH custom properties generated by `scripts/palette.mjs` from `palette.config.mjs`:
- 11-step ramps for the neutral (tinted toward 320 at chroma 0.012), brand (plum) and accent (mint);
- single tokens for the six candies and their darker rims;
- semantic tokens: `bg`, `surface`, `surface-2`, `text`, `text-muted`, `border`, `accent`, `accent-contrast`, `focus`;
- hex fallbacks under `@supports not (color: oklch(0 0 0))`.

Gradients interpolate `in oklch`, with a plain fallback declared first. The large "Ready for a first jar?" gradient has the SVG grain overlay.

## Motion system
The shared tokens (durations 0.4/0.7/1.0/1.2 s, expo and power3 easing, 75 ms stagger, the pop preset) live in `src/styles/motion.css` and `src/lib/motion.ts`. This site sets `--pop-ease` to a back-out spring and adds `--ease-squish`, a CSS `linear()` spring with a cubic-bezier fallback.

| Section | Choreography |
|---|---|
| Hero | Split-text h1 (word rise), a bouncy "For savers" label, and two goal chips that **pop at 0.8 s and 1.0 s**. **Parallax:** three blurred background blobs at three speeds. Gentle idle float on the coins and a "breathing" mochi (off under reduced motion). |
| How it works | Three clay cards pop in staggered; the middle one is offset for rhythm. |
| Simulator | Panels pop up; coins drop with `bounce.out`; the jar fill springs. |
| Year | **Pinned and scrubbed** (220% of scroll). Badges **pop at specific scroll positions**, the points where the sample story crosses $10, $60 and $120. |
| Grown-ups | Split-text heading, phone figure pop, and feature cards staggered in a zig-zag. |
| Get the app | Split-text heading and staggered buttons. |

Scrubbed parallax uses CSS `animation-timeline: view()` when supported, with a GSAP ScrollTrigger fallback (`?nosda` forces it). Hidden start states apply only under `html.js`.

Under `prefers-reduced-motion`:
- final states show at once;
- the year section is a static, finished jar with all badges visible;
- no parallax, idle float, coin drops or squish springs;
- the simulator still works, it just updates instantly.

## Skills actually used
- `design-style` (nakanosanku/ohmyskills), **Claymorphism** prompt: the 4-layer shadow stack, the super-rounded rule, squish states and buoyancy.
- `claymorphism` (bergside): I read its SKILL.md for its accessibility gates (avoid low-contrast text, explicit states).
- `motion-and-interaction-system` (read manually; the Skill tool would not register it): squish as tier-1 feedback, one cinematic sequence, mandatory reduced motion.
- Not available in this session, so **not used**: frontend-design-pro, taste-skill, gsap-web, color-expert, accesslint. Colour work used my own OKLCH scripts. The accessibility audit used axe-core 4.13 in Playwright instead of accesslint.

```bash
npm install
npm run dev

npm run preview
npm run palette    # regenerate tokens.css

```

## Swap in your own photos
Put images in `public/assets/images/` and set `data-photo="assets/images/<file>"` on a `.fig` slot in `index.html`. See [`public/assets/README.md`](public/assets/README.md). Slots fade in from a blur over a candy placeholder colour. The duotone overlay (`--fig-duo`) keeps photos in the candy palette; set it to `0` for natural colour.

## Notes and decisions
- Built as a folder in `erdgib923-star/different-websites`, not its own repo: `gh` was not authenticated and repo creation was unavailable in this session. Use `style-sites-2/publish-repos.sh` to split it out later.
- Brand check (web search, 2026-11-02): one small adult budgeting app called "Mochi Money" appears on an app-aggregator listing. It is not a kids' product and not a well-known brand, so the name was kept. Rename it before any public use.
- Fonts are self-hosted via `@fontsource` (Google Fonts families, `font-display: swap`).
